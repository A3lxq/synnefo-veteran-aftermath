# Case File 7: Aftermath

This isn't a live system Priya Okonkwo-Reyes flagged — it's what
Halcyon's own incident-response team pulled together the night her
access was finally revoked. A case manifest, an auth log, a web log, a
packet capture, a process snapshot, a disk excerpt. Standard evidence
handling, chain of custody intact.

One thing in the handover notes stands out: the host these all came
from was isolated, not shut down. It's still running, waiting for
someone with the right credentials.

Her note isn't here this time. This is the file where she stopped
writing them.
